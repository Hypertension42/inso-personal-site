PROJECT FILE

AI Agent 应用开发实习生 · 完整性检查模块

我的工作

负责投标完整性检查模块、合成数据评测、跨行抓值修复、涂黑与密文字段检测，以及文档定位搜索。

让评测可以复现

固定 seed 生成 628 条规则测试样本，配套黄金答案。定位模型从其他行抓取值导致的漏检，用行级摘录切分、确定性守卫与 prompt 规则共同约束检查过程。

指标的范围

缺席字段检出准确率从 24% 提升到 50%。这是特定检查任务的评测结果，检出率仍需继续提高。

把判断带回证据

实现像素级涂黑与密文字段检测，通过 OCR 页面索引与全库检索支持证据定位和回溯；对比 5 种 OCR 引擎完成选型。

团队与个人的分工

团队系统覆盖招标解析、规则生成、批量审查和报告导出，拥有 436 项单元测试。我的主要贡献是完整性检查、评测与错误修复。

参与资源托管、授权、审计与多角色协作演示

项目做什么

让多智能体之间的推理资源可以托管、授权和审计，形成 P2P 推理容量银行。

我的参与

实现资源托管、授权与审计闭环；开发跨境贸易合规 ToB 演示系统，组织多角色智能体协作流程，配套对话检测与 Telegram Bot。

成果与范围

团队获得南客松 S2 agent-network 赛道一等奖。公开仓库展示项目实现与演示，成果属于团队协作。

全栈开发 · 浏览器端检测与 AI 解读

从图像到关键点

使用 MediaPipe 在浏览器本地提取身体关键点，原始图像不上传。

从关键点到体验

结合大模型生成体态解读与穿搭指南，完成全栈 AI 演示产品，获得徽客松 S3 二等奖。

展示范围

项目是姿态解读与穿搭演示。原图留在本地，是图像处理流程的选择；这不代表所有衍生数据都仅在本地处理。

独立完成业务设计、前后端开发与部署交付

完整的业务链路

使用 Vue 3 与 NestJS 完成全栈开发，覆盖用户、题库、考试、AI 测评、支付、后台管理等 12 个业务模块。

外部服务与交付

集成大模型、OCR、短信与支付等第三方服务，以 Docker 容器化并通过 CI/CD 部署。
